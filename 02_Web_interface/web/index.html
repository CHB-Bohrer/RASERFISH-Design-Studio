What the two policies do and do not establish

Strict mode treats every loaded gene/transcript span, including introns, as a potential RNA and excludes conflicting candidates regardless of cell-line expression. Default transcript-only mode does not generate those inferred unspliced references; it searches the RNA database and explicit RNA inputs. Both are reference-scoped heuristics, not RNA-DNA melting-temperature models or proof of zero RNA labeling. RNase cleanup, unannotated/antisense/nascent RNAs and experimental controls remain separate.

04

Set the QC rules used to choose probes

These are selection rules, not just display filters. A candidate failing a required rule is not selected. Changing any rule requires a new design run.

The active user preset uses 45-55 C and adaptive lengths; it is not the original Ellenberg window. Published values and project fallbacks remain separately labeled. Additional QC cutoffs are heuristics, not validated experimental failure thresholds. The program reports underfilled regions instead of relaxing QC to reach a target count.

Starting parameters and their source

Applying a preset never edits the existing order, target sequence, imager assignments, or tracing-region boundaries.

Show reported paper values versus project fallbacks

The current user preset prefers 36-42 nt arms, permits QC-tested extensions up to 90 nt, and uses a 45-55 C on-target Tm window. Legacy settings files can still be imported; the active preset restores the verified ERRFI1 QC values. Paper-reported LDA/k-mer rules are described below but are not claimed to be implemented here.

05

Generate candidates, screen, and select

The engine searches alternatives at different positions and lengths. It applies the requested QC and spacing rules before selecting sites across the tracing regions. Cross-primary compatibility is not assessed when probe-probe screening is OFF.

1. EnumerateOne fixed tracing strand; reject RNA conflicts; alternative arms, GC and Tm filters.
2. ScreenIntended sites, genome/RNA, whole-primary folding.
3. SelectBalance counts and distribution; enforce spacing and the selected interaction policy.
4. VerifyRecheck all site strands and requested checks; record omitted analyses; write a DRAFT order.

Concise output saves each primary's QC scores, decisions, sequences, region summary, and original settings. Raw alignments, per-base folding values, and pair-coordinate lists are omitted. Full audit explicitly retains detailed evidence and may use substantial disk space. Both modes apply the same scientific checks.

Automatic restart: ON for new Standard runs. Verified checkpoints are reused after an interruption.

Automatic recovery tries at most twice: after 30 seconds, then after 2 minutes. Cancellation, memory/resource stops, and damaged or incompatible checkpoints stop automatic recovery. The analysis remains INCOMPLETE until every required check finishes.

Public feature downloads send only the requested cell line / genomic coordinates; no primary sequence is submitted to public BLAST.

Saved checkpoints

Resume uses the saved run's original inputs and scientific settings. Current edits in the controls are replaced by those saved settings. Completed checkpoints are verified before reuse; unfinished work is rerun. A saved checkpoint is not a PASS or a completed order.

How to read the plot and annotation limits
Bars count binding-site centers in consecutive 1-kb sectors. The final sector can be shorter. Ticks mark individual sites; the diamond marks their mean position and the vertical line marks the region midpoint. The mean offset follows increasing reference-local coordinates. It is a sequence sampling measure, not a measured 3D centroid error.
Boxes show exons; arrows show transcription direction. The gene overview combines all overlapping isoforms; Individual transcripts separates them. Annotation does not establish expression or RNA binding. Potential intron matches are assessed within each transcript, not from merged exon tracks.
