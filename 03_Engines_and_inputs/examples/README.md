# Synthetic tutorial fixtures

These JSON files are bundled demonstrations and regression fixtures from earlier
Studio versions. They are local-only previews, not completed genomic/RNA QC or
probe order recommendations. Their saved versions and policies are preserved.

`compact_demo/design_result.json` is used by the live UI's tutorial;
`local_design/design_result.json` is also used by regression checks.
Generated CSV order files and stale standalone HTML viewers are intentionally
omitted from this source package.
